# 云南财经大学 真一网通 自动登录插件
 
## 支持一网通认证、校园网认证、教务系统全自动登录的浏览器插件。
 
## 功能与特点
 
- 所有一网通认证页面自动填写账号密码并自动登录
- 校园网一键登录，教务系统一键登录
- 教务系统通过一网通跳板实现免教务系统独立密码登录
- 适配深蓝网络加密登录要求，实现同款加密算法，保证稳定快速登录
- 加解密与账号信息全程本地处理，无云端传输，安全不泄露
 
## 安装教程
 
### Chrome
 
1. 打开  chrome://extensions/ 
2. 开启开发者模式
3. 将插件文件直接拖入页面导入
 
### Edge
 
1. 打开  edge://extensions/ 
2. 开启开发者模式
3. 将插件文件直接拖入页面导入
 
### Firefox
 
1. 打开  about:debugging#/runtime/this-firefox 
2. 点击「临时载入附加组件」
3. 选择插件文件导入
 
### 其他浏览器（夸克/360/百分等国产以及魔改浏览器）
 
大部分为 Chrome 内核，找到扩展/插件管理，打开开发者设置，将插件文件拖入导入即可。
 
## 使用说明
 
1. 点击插件图标，输入并保存一网通账号密码
2. 进入任意一网通界面，插件会自动填写账号密码并自动登录
3. 打开插件后，点击校园网登录即可一键自动登录校园网
4. 点击教务系统按钮即可一键自动登录教务系统
